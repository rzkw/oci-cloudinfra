### Task 3: Simplify instances module variables

**Files:**
- Modify: `terraform/instances/variables.tf`
- Modify: `terraform/instances/main.tf`

**Interfaces:** Renamed variables consumed by `main.tf` resource block. `source_type` hardcoded to `"image"` — removed as variable.

- [ ] **Step 1: Rename flex variables**

In `variables.tf`, rename:
- `instance_flex_memory_in_gbs` → `memory_in_gbs`
- `instance_flex_ocpus` → `ocpus`

In `main.tf`, update references:
- `var.instance_flex_memory_in_gbs` → `var.memory_in_gbs`
- `var.instance_flex_ocpus` → `var.ocpus`

- [ ] **Step 2: Remove `source_type` variable and hardcode in resource**

Remove the `source_type` variable from `variables.tf`. In `main.tf`, hardcode:
```hcl
  source_details {
    boot_volume_size_in_gbs = var.boot_volume_size_in_gbs
    source_id               = var.source_ocid
    source_type             = "image"
  }
```

- [ ] **Step 3: Simplify metadata ssh_authorized_keys handling**

Replace the ternary in `main.tf` metadata block:
```hcl
    ssh_authorized_keys = var.ssh_public_keys != null ? var.ssh_public_keys : ""
```
with a dynamic block to omit the key entirely when null:
```hcl
  metadata = {
    user_data          = var.user_data_path != null ? base64encode(file(var.user_data_path)) : null
    tailscale_auth_key = var.tailscale_auth_key
  }

  dynamic "metadata" {
    for_each = var.ssh_public_keys != null ? [1] : []
    content {
      ssh_authorized_keys = var.ssh_public_keys
    }
  }
```

Note: OCI provider does not support `dynamic` for `metadata` (it's a map, not a block). Use the ternary as-is — it's correct. Skip this step if provider rejects dynamic syntax during validate.

- [ ] **Step 4: Validate**

```bash
terraform -chdir=terraform/instances init -backend=false && terraform -chdir=terraform/instances validate
```

- [ ] **Step 5: Commit**

```bash
git add terraform/instances/variables.tf terraform/instances/main.tf
git commit -S -m "refactor(instances): rename flex vars, hardcode source_type, simplify"
```
